Privacy Policy

Matematik Adası
Last updated: August 27, 2026

In brief: Matematik Adası is an educational game designed to teach addition, subtraction, multiplication, and division through an engaging game experience. The application is not designed to collect personal information or share user data for advertising purposes.

1. About the Application

Matematik Adası is an educational mathematics game designed to help children and students develop basic arithmetic skills. The application provides gamified exercises covering addition, subtraction, multiplication, and division.

2. Personal Data We Collect

Matematik Adası does not directly collect personal or sensitive user information such as names, email addresses, telephone numbers, precise location, photographs, camera data, or microphone data.

The application does not require account creation or user login.

3. Application Data and Game Progress

To provide a continuous game experience, certain game state and progress information may be stored locally on the user's device. This information is used solely to operate the application and preserve game progress.

These locally stored data are not sent to a remote server by the application and are not shared with third parties. Such data may be deleted when the application is uninstalled or when Android application data is cleared.

4. Internet Access and Data Transfer

Matematik Adası does not require an internet connection for its core functionality. The application is not designed to transmit personal user data to a remote server.

5. Advertising

Matematik Adası does not use advertising networks or advertising SDKs to display advertisements. Therefore, no user data is collected or shared for personalized advertising purposes.

6. Third-Party Services and SDKs

The core functionality of the application does not rely on third-party advertising, analytics, or user-tracking services. If the application later introduces a third-party service or changes its data processing practices, this Privacy Policy will be updated accordingly.

7. Children's Privacy

Matematik Adası is designed as an educational application that may be used by children. The application does not request personal information from children and is not designed to collect personal information from children.

The application aims to protect children's privacy and safety and to comply with applicable Google Play Families requirements.

8. Data Security

Matematik Adası does not send personal data to a remote server or transfer personal data to third parties. Application data stored on the device are kept within Android's application data storage area.

9. Data Retention and Deletion

Matematik Adası does not create a central user account or a server-side user profile. Game progress data stored locally by the application may be deleted when the user clears the application's data or uninstalls the application.

Because the application does not use a central account system, there is no user account requiring a separate account-deletion process.

10. Changes to This Privacy Policy

If the application's data practices change, this Privacy Policy will be updated. The updated policy will be published on this page and the last-updated date will be revised.
